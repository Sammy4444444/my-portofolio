# 🌌 My Portfolio


A modern interactive portfolio showcasing my journey as a Computer Science student and developer. This project combines immersive UI design, 3D graphics, creative web experiences, and personal projects into a single responsive website.

Built using **React**, **TypeScript**, **Vite**, **Three.js**, **Tailwind CSS**, and **Framer Motion**.

---

# 🚀 Overview

This portfolio is more than just a personal website. It serves as a central hub where I showcase my projects, technical skills, learning resources, creative experiments, and interests in software engineering and computer graphics.

The goal is to create a portfolio that feels engaging, interactive, and memorable while demonstrating modern frontend development techniques.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Sammy4444444/my-portofolio.git
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build for production

```bash
npm run build
```
